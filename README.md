# Decimal (s21_decimal)

Собственная реализация библиотеки **s21_decimal** на языке C — аналог типа `decimal` из .NET/`DECIMAL` из C#. Проект в рамках **School 21 / C_Bootcamp**.

## О проекте

`s21_decimal` — это тип данных для точных вычислений с десятичными числами (128-битное десятичное число), который хранится в структуре из четырёх 32-битных слов. В отличие от чисел с плавающей точкой (float/double), decimal исключает ошибки округления, что критично для финансовых и денежных расчётов.

## Реализованный функционал

### Арифметика
- `s21_add` — сложение
- `s21_sub` — вычитание
- `s21_mul` — умножение
- `s21_div` — деление

Возвращают код ошибки: 0 — успех, 1 — переполнение (или деление на ноль), 2 — переполнение с отрицательным результатом.

### Сравнение
Сравнение двух значений, возвращают `1` если истинно и `0` иначе: `less`, `less_or_equal`, `greater`, `greater_or_equal`, `equal`, `not_equal`.

### Конвертация
Перевод между `int`, `float` и `decimal` в обе стороны. Учитывают переполнение и точность.

### Прочее
- `s21_floor` — округление в сторону минус бесконечности
- `s21_round` — округление к ближайшему целому (банковское)
- `s21_truncate` — отбрасывание дробной части
- `s21_negate` — инверсия знака

## Особенности реализации

- Битовое представление числа: мантисса 96 бит, масштаб (scale) 8 бит, знак 1 бит.
- Внутреннее использование расширенного типа `big_decimal` (7 слов) для промежуточных вычислений и нормализации масштабов.
- Степени десятки предрассчитаны в таблице `ten_pows`.
- Банковское (инженерное) округление при потере точности.
- Обработка переполнений и деления на ноль через коды возврата.

## Сборка и тесты

Из каталога `src`:

```bash
make            # сборка статической библиотеки s21_decimal.a и запуск тестов
make clean      # удаление сборочных файлов
make gcov_report # отчёт о покрытии кода (lcov)
```

Требуется компилятор `gcc` и библиотека тестирования `Check`.
